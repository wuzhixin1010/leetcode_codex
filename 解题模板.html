1、哈希表

**适用：** 需要快速判断元素是否出现、记录元素位置或统计频次的问题，例如两数之和、字母异位词分组、最长连续序列。

**模板代码：**

unordered_map<int, int> mp;
for (int i = 0; i < nums.size(); ++i) {
    int need = target - nums[i];
    if (mp.count(need)) return {mp[need], i};
    mp[nums[i]] = i;
}
return {};

**例题及代码题解：**

例题 1：1. 两数之和

遍历当前元素 x 时，目标是寻找 target - x。把已经遍历过的元素放入哈希表，就能把查找从 O(n) 降到 O(1)。

vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int, int> mp;
    for (int i = 0; i < nums.size(); ++i) {
        int need = target - nums[i];
        if (mp.count(need)) return {mp[need], i};
        mp[nums[i]] = i;
    }
    return {};
}

时间 O(n)，空间 O(n)。

例题 2：49. 字母异位词分组

将每个单词排序后的结果作为哈希键，键相同的单词一定属于同一组。

vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> mp;
    for (string word : strs) {
        string key = word;
        sort(key.begin(), key.end());
        mp[key].push_back(word);
    }
    vector<vector<string>> answer;
    for (auto& [key, words] : mp) answer.push_back(move(words));
    return answer;
}

时间约为 O(n * k log k)，k 为单词长度。

例题 3：560. 和为 K 的子数组

若当前前缀和为 sum，历史上出现过 sum - k 的位置都能形成合法子数组，因此哈希表记录的是前缀和出现次数。

int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> count{{0, 1}};
    int sum = 0, answer = 0;
    for (int x : nums) {
        sum += x;
        answer += count[sum - k];
        ++count[sum];
    }
    return answer;
}

时间 O(n)，空间 O(n)。

**适用：** 数组有序、需要从两端向中间搜索，或需要原地维护有效区间的问题，例如盛最多水的容器、三数之和、移动零。

**例题及代码题解：**

例题 1：11. 盛最多水的容器

面积由较短的边决定。移动较长的一边不会增加短边高度，因此每次移动较短的一边。

int maxArea(vector<int>& height) {
    int left = 0, right = height.size() - 1, answer = 0;
    while (left < right) {
        answer = max(answer, min(height[left], height[right]) * (right - left));
        if (height[left] < height[right]) ++left;
        else --right;
    }
    return answer;
}

时间 O(n)，空间 O(1)。

例题 2：15. 三数之和

思路

目标是寻找所有 a + b + c = 0 的不重复三元组。直接枚举三个下标需要 O(n^3)，即使先固定一个数，剩下两个数仍可以通过双指针优化为 O(n^2)。

  1. 先排序。排序后，固定 nums[i]，剩余区间 [i + 1, n - 1] 有序，可以用左右指针判断下一步向哪边移动。
  2. 固定第一个数 nums[i]，令 left = i + 1、right = n - 1。
  3. 计算三数之和：
  • sum < 0：和太小，需要增大它，因此 left++；
  • sum > 0：和太大，需要减小它，因此 right--；
  • sum == 0：记录答案，然后同时移动左右指针。
  1. 去重是本题的重点：
  • 如果 nums[i] == nums[i - 1]，当前固定值产生的组合与上一次完全重复，直接跳过；
  • 找到答案后，跳过连续相同的 nums[left] 和 nums[right]，避免同一层重复记录；
  • 不能在进入下一轮时无条件跳过所有重复元素，否则可能错过同一固定值下的合法组合，去重应放在对应指针移动的位置。
  1. 当 nums[i] > 0 时可以提前结束：由于数组已经排序，后面的数都不小于 nums[i]，三数之和不可能再等于 0。

代码题解

vector<vector<int>> threeSum(vector<int>& nums) {
    vector<vector<int>> answer;
    sort(nums.begin(), nums.end());

    const int n = static_cast<int>(nums.size());
    for (int i = 0; i < n - 2; ++i) {
        // 同一层固定值去重。
        if (i > 0 && nums[i] == nums[i - 1]) continue;

        // 排序后，固定值已经大于 0，后面不可能凑出 0。
        if (nums[i] > 0) break;

        int left = i + 1;
        int right = n - 1;
        while (left < right) {
            const long long sum = static_cast<long long>(nums[i])
                                + nums[left]
                                + nums[right];

            if (sum < 0) {
                ++left;
            } else if (sum > 0) {
                --right;
            } else {
                answer.push_back({nums[i], nums[left], nums[right]});
                ++left;
                --right;

                // 找到一个解后，跳过左右两侧的重复值。
                while (left < right && nums[left] == nums[left - 1]) ++left;
                while (left < right && nums[right] == nums[right + 1]) --right;
            }
        }
    }
    return answer;
}

例如 [-1, 0, 1, 2, -1, -4] 排序后为 [-4, -1, -1, 0, 1, 2]。固定 -1 时，左右指针可以找到 [-1, -1, 2] 和 [-1, 0, 1]；第二个 -1 会被固定值去重逻辑跳过。

时间复杂度为 O(n^2)：排序为 O(n log n)，外层枚举和内层双指针合计 O(n^2)；额外空间复杂度为 O(1)，不计算返回结果和排序实现可能使用的栈空间。

例题 3：283. 移动零

思路

题目要求将所有 0 移到数组末尾，同时保持非零元素的相对顺序，并且必须原地修改数组。因此核心是把问题拆成两个阶段：

  1. 从左到右扫描数组，稳定地收集所有非零元素；
  2. 扫描结束后，剩余位置自然由 0 填充。

可以使用快慢指针：

  • fast：负责遍历每一个元素，不能漏掉任何位置；
  • slow：指向下一个应该放置非零元素的位置，也就是当前有效非零区间的右边界。

扫描到 nums[fast] == 0 时，说明这个零暂时留在当前位置，slow 不动；扫描到非零元素时，将它交换到 slow，再让 slow++。

以 [0, 1, 0, 3, 12] 为例：

| 扫描到的元素 | slow 指向 | 操作 | 数组状态 |

| --- | ---: | --- | --- |

| 0 | 0 | 跳过，slow 不变 | [0, 1, 0, 3, 12] |

| 1 | 0 | 与 nums[0] 交换，slow++ | [1, 0, 0, 3, 12] |

| 0 | 1 | 跳过，slow 不变 | [1, 0, 0, 3, 12] |

| 3 | 1 | 与 nums[1] 交换，slow++ | [1, 3, 0, 0, 12] |

| 12 | 2 | 与 nums[2] 交换，slow++ | [1, 3, 12, 0, 0] |

循环不变量

在每次处理完 fast 后：

  • [0, slow) 中全部是已经收集好的非零元素，并且顺序与原数组一致；
  • slow 左侧的元素不再需要处理；
  • fast 负责继续向右探索剩余元素。

因此，非零元素会按照出现顺序依次写入数组前部，零元素会被交换到后面。整个过程只使用两个下标，不需要额外数组。

代码题解

void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast) {
        if (nums[fast] == 0) continue;

        swap(nums[slow], nums[fast]);
        ++slow;
    }
}

当数组前面没有零时，slow == fast，交换只是自己与自己交换，不影响结果；也可以额外判断 if (slow != fast) 来减少无意义交换。

时间复杂度为 O(n)，每个元素最多被快指针访问一次；额外空间复杂度为 O(1)。由于非零元素按照原出现顺序写入，算法天然满足稳定性要求。

例题 1：3. 无重复字符的最长子串

窗口扩张后，如果出现重复字符，就移动左端点直到窗口重新合法。

int lengthOfLongestSubstring(string s) {
    vector<int> last(128, -1);
    int left = 0, answer = 0;
    for (int right = 0; right < s.size(); ++right) {
        left = max(left, last[s[right]] + 1);
        last[s[right]] = right;
        answer = max(answer, right - left + 1);
    }
    return answer;
}

例题 1：203. 移除链表元素

你的公开题解中使用了 first / pre / cur 三个指针，并处理头部连续删除。C++ 中用虚拟头节点可以统一所有情况。

ListNode* removeElements(ListNode* head, int val) {
    ListNode dummy(0, head);
    ListNode* prev = &dummy;
    ListNode* cur = head;
    while (cur) {
        if (cur->val == val) prev->next = cur->next;
        else prev = cur;
        cur = cur->next;
    }
    return dummy.next;
}

时间 O(n)，空间 O(1)。

ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* cur = head;
    while (cur) {
        ListNode* next = cur->next;
        cur->next = prev;
        prev = cur;
        cur = next;
    }
    return prev;
}

void backtrack(State& state) {

例题 1：46. 全排列

你的账号笔记已经记录了标准框架。用 used[i] 表示数字是否已经在当前路径中。

vector<vector<int>> answer;
vector<int> path;

void dfs(vector<int>& nums, vector<bool>& used) {
    if (path.size() == nums.size()) {
        answer.push_back(path);
        return;
    }
    for (int i = 0; i < nums.size(); ++i) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(nums[i]);
        dfs(nums, used);
        path.pop_back();
        used[i] = false;
    }
}

例题 1：34. 在排序数组中查找元素的第一个和最后一个位置

int lowerBound(vector<int>& nums, int target) {
    int left = 0, right = nums.size();
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
}

vector<int> searchRange(vector<int>& nums, int target) {
    int left = lowerBound(nums, target);
    int right = lowerBound(nums, target + 1) - 1;
    if (left == nums.size() || nums[left] != target) return {-1, -1};
    return {left, right};
}

int findKthLargest(vector<int>& nums, int k) {

    return pq.top();

11、贪心

bool canJump(vector<int>& nums) {
    int farthest = 0;
    for (int i = 0; i < nums.size(); ++i) {
        if (i > farthest) return false;
        farthest = max(farthest, i + nums[i]);
    }

}

例题 2：300. 最长递增子序列

你的账号笔记已经强调了状态定义。dp[i] 表示以 nums[i] 结尾的最长递增子序列长度。

int lengthOfLIS(vector<int>& nums) {
    vector<int> dp(nums.size(), 1);
    int answer = 0;
    for (int i = 0; i < nums.size(); ++i) {
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) dp[i] = max(dp[i], dp[j] + 1);
        }
        answer = max(answer, dp[i]);
    }
    return answer;
}

时间 O(n^2)，空间 O(n)。

例题 3：416. 分割等和子集

你的账号笔记已经将它归纳为 0-1 背包。目标是选出总和一半的子集；一维背包容量必须从后向前更新。

bool canPartition(vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum % 2) return false;
    int target = sum / 2;
    vector<bool> dp(target + 1, false);
    dp[0] = true;
    for (int x : nums) {
        for (int j = target; j >= x; --j) {
            dp[j] = dp[j] || dp[j - x];
        }
    }
    return dp[target];
}

13、图论与 BFS / 拓扑排序

**适用：** 网格连通块、最短层数、依赖关系、判断有向图是否有环。

**模板代码：**

queue<int> q;
vector<int> indegree(n, 0);
for (auto& edge : edges) {
    graph[edge[0]].push_back(edge[1]);
    ++indegree[edge[1]];
}
for (int i = 0; i < n; ++i) {
    if (indegree[i] == 0) q.push(i);
}
int visited = 0;
while (!q.empty()) {
    int u = q.front();
    q.pop();
    ++visited;
    for (int v : graph[u]) {
        if (--indegree[v] == 0) q.push(v);
    }
}
return visited == n;

例题 1：207. 课程表

课程是节点，先修关系是有向边。不断删除入度为零的课程；如果最后处理的课程数等于总课程数，说明没有环。

bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
    vector<vector<int>> graph(numCourses);
    vector<int> indegree(numCourses, 0);
    for (auto& edge : prerequisites) {
        graph[edge[1]].push_back(edge[0]);
        ++indegree[edge[0]];
    }
    queue<int> q;
    for (int i = 0; i < numCourses; ++i) {
        if (indegree[i] == 0) q.push(i);
    }
    int visited = 0;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        ++visited;
        for (int v : graph[u]) {
            if (--indegree[v] == 0) q.push(v);
        }
    }
    return visited == numCourses;
}
